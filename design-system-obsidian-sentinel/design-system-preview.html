Design System · v1.0.0

Obsidian Sentinel

A precision command-console system for AD-SIEM. Built for eight-hour shifts: a five-step severity ramp readable in peripheral vision, monospace for every technical value, and geometry sharp enough to feel like operations software, not a themed dashboard template.

Typography

IBM Plex Sans for UI and prose, IBM Plex Mono for anything technical — IPs, hashes, hostnames, rule IDs, timestamps. One type family, two registers, so headers and the data beneath them never clash.
