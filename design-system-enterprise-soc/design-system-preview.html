Design System · v1.0.0

Ironwatch

Industrial-grade design system for AD-SIEM. Built to look like instrumentation an analyst trusts — reference points are Splunk Enterprise Security, Microsoft Sentinel, IBM QRadar, Elastic Security, and CrowdStrike Falcon, not a startup dashboard.

PRIMARY: Archivo / Public Sans / JetBrains Mono BASE UNIT: 4px RADIUS: 2–8px (no bubbles)

Typography

Public Sans is the U.S. federal government's own accessibility-first typeface (USWDS) — chosen for legibility, not personality. Archivo carries display weight. Inter/Roboto/system-ui are never used as the primary face.
